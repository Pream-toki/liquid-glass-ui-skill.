# Contributing

Thanks for helping improve Liquid Glass UI Skill.

## Principles
- Prefer concrete implementation guidance over vague style adjectives.
- Keep Apple-specific API claims linked to current official documentation.
- State SDK and OS availability when relevant.
- Do not claim code was compiled or tested unless it was.
- Keep accessibility and fallbacks part of the design, not optional extras.

## Pull requests
Please include:
1. The problem being solved
2. The target platform and SDK context
3. Links to official documentation for API-specific changes
4. A before/after explanation or minimal example where useful
5. Accessibility and compatibility considerations
